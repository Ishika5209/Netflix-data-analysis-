# 🎬 Netflix Data Analysis

## 📌 Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a Netflix movies dataset using Python.  
The main objective of this project is to answer key analytical questions and extract meaningful insights from the data.

---

## 🎯 Problem Statements
The analysis in this project is focused on answering the following questions:

- Which movie has the highest vote average?
- What movie has the highest popularity and what is its genre?
- Which year has the highest number of movie releases?
- What movie has the lowest popularity and what is its genre?
- What is the most frequent genre of movies released on Netflix?

---

## 🛠️ Tools & Technologies Used
- Python 🐍
- Pandas
- NumPy
- Seaborn
- Jupyter Notebook

---

## 📊 Key Analysis Performed
- Data Cleaning (handling missing values)
- Genre column preprocessing (splitting & exploding)
- Sorting and filtering data
- Grouping and aggregation
- Visualization using Seaborn

---

## 📈 Key Insights
- Identified movies with highest and lowest popularity
- Determined the most frequent genre on Netflix
- Found the year with maximum movie releases
- Analyzed vote averages across movies
